# 러닝 리뷰 EDA 발표

15장 HTML 슬라이드 덱, 약 8–10분. `index.html`을 브라우저에서 열면 됩니다.

- 방향키 / Space: 다음 내용 또는 슬라이드
- N / 노트 버튼: 현재 슬라이드의 발표자 노트
- 슬라이드 선택: 원하는 장으로 바로 이동
- 전체 화면 버튼: 발표 화면
- 모바일: 좌우 스와이프 / 버튼
- 움직임 줄이기 설정 지원, 인쇄 시 모든 내용 표시

발표자 노트는 `speaker-notes.md`, 상세 보고서는 `report.html`입니다.
분모와 수집 한계는 각 슬라이드 및 부록에 표시했습니다. 데이터는 리뷰 원문이 아닌 공개 요약이며 개인 작성자명을 저장하지 않습니다.

## 이미지

현재 그림은 직접 제작한 SVG입니다. Nano Banana 이미지가 아닙니다.
`image-prompts.json`에 Nano Banana용 이미지 제작 지시와 교체 위치를 준비했습니다. 모델 연결 후 이미지를 생성하고 코드의 이미지 경로를 교체해야 합니다.

## GitHub Pages 배포

발표자료와 공개 요약 데이터만 별도 저장소로 배포합니다. 로컬 프로젝트의 스킬·node_modules 등은 포함하지 않습니다.

```sh
./deploy.sh musinsa-running-review-slides
```

인증이 없으면 CLI가 브라우저 로그인을 시작합니다. 스크립트는 새 공개 저장소를 만들고 GitHub Actions 기반 Pages를 활성화한 후 배포 결과 URL을 출력합니다. 기존 원격 저장소가 있다면 그 저장소를 사용합니다.

현재 제작 환경에서는 GitHub DNS 연결과 인증이 실패하여 실제 배포는 완료되지 않았습니다.
